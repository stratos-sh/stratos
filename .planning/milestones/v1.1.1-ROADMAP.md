**Status:** Complete (shipped 2026-02-04)

## Overview

Pure refactoring milestone: rename three types to match their actual roles, rename two files to follow subject_role.go convention, remove one dead method, and replace one unsafe interface{} field with a concrete type. No new features, no API surface changes. Five phases in strict dependency order -- dead code first (independent), then type renames via gopls (needs stable file paths), then file renames via git mv (after gopls is done), then the structural type change (independent but logically last).
