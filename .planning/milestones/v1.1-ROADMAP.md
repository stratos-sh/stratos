# Milestone v1.1: Simplify Scaling

**Status:** SHIPPED 2026-02-04
**Phases:** 7-11
**Total Plans:** 5

## Overview

Remove the ScalingStrategy abstraction and GitHub Actions support. Stratos becomes Kubernetes-only with direct scaling logic. Delete ~1,100 LOC of abstraction, simplify controller wiring, clean CRD surface.

## Milestone Summary

**Key Decisions:**
- Remove ScalingStrategy interface (Rationale: Only K8s supported, GHA becomes separate project)
- Direct package import over merge (Rationale: Keep scaling logic in its own package rather than merging into controller)
- Remove CRD fields as breaking change (Rationale: Clean API surface, no deprecated fields)
- Type aliases for zero-overhead migration (Rationale: Zero consumer changes during relocation)
- Single scaler field replaces per-pool cache (Rationale: Strategy is stateless, caching unnecessary)
- +kubebuilder:object:generate=false for interfaces (Rationale: Prevents invalid deepcopy generation)

**Issues Resolved:**
- controller-gen failure on NodeClass interface (fixed with kubebuilder marker)
- Dead RBAC Secrets permission (removed in Phase 11)
- Dead drainHelper recorder field (removed in Phase 11)

**Issues Deferred:**
None — clean milestone with no deferred issues.

None — clean milestone.
