All changes below are tightly coupled (intermediate state won't compile), so apply them as one atomic unit.

**reconciler.go:**
1. Replace import `"github.com/stratos-sh/stratos/internal/strategy"` with `"github.com/stratos-sh/stratos/internal/scaling"`.
2. Remove the `strategiesMu sync.RWMutex` and `strategies map[string]strategy.ScalingStrategy` fields from the Reconciler struct. Add a `scaler *scaling.Strategy` field.
3. In `reconcileNodePool()`: remove the `scaler, err := r.getOrCreateStrategy(nodePool)` block (lines 164-167). Replace with `scaler := r.scaler`. Pass `scaler` to all helpers as before.
4. In `startStandbyNodes()`: change parameter type from `scaler strategy.ScalingStrategy` to `scaler *scaling.Strategy`. Change `r.newNodeManager(provider, scaler)` to `r.newNodeManagerWithHooks(provider)`.

**provider_cache.go:**
1. Remove imports: `"github.com/stratos-sh/stratos/internal/strategy"`, `"github.com/stratos-sh/stratos/internal/strategy/githubactions"`, `"github.com/stratos-sh/stratos/internal/strategy/kubernetes"`.
2. Add import: `"github.com/stratos-sh/stratos/internal/scaling"`.
3. Remove the compile-time assertion `_ lifecycle.NodeHooks = (*githubactions.Strategy)(nil)`. Change the kubernetes assertion to: `_ lifecycle.NodeHooks = (*scaling.Strategy)(nil)`.
4. Replace the variadic `newNodeManager` with two explicit methods:
   - `newNodeManager(provider cloudprovider.CloudProvider) *lifecycle.Manager` -- no hooks, just calls `lifecycle.NewManager(r.Client, r.Recorder, provider, r.ClusterName)`. This is used by `replenishStandby` which intentionally skips hooks for launch-only path.
   - `newNodeManagerWithHooks(provider cloudprovider.CloudProvider) *lifecycle.Manager` -- calls `newNodeManager(provider).WithNodeHooks(r.scaler)`. This is used by all other call sites that need scaling hooks.
5. Delete the `getOrCreateStrategy()` method entirely.
6. Delete the `newStrategy()` function entirely.
7. Remove the `events` and `client` imports (no longer needed after deleting newStrategy). Keep `context`, `fmt`, and cloud provider imports since ensureCloudProvider still needs them.

**reconciler_helpers.go:**
1. Replace import `"github.com/stratos-sh/stratos/internal/strategy"` with `"github.com/stratos-sh/stratos/internal/scaling"`.
2. Change all `scaler strategy.ScalingStrategy` parameters to `scaler *scaling.Strategy` in these methods:
   - `handleScaleUp` (line 40)
   - `handleMonitoring` (line 76)
   - `handleScaleDown` (line 100)
   - `processScaleDownCandidate` (line 132)
   - `handleMaxRuntimeRecycling` (line 171)

   - `processScaleDownCandidate` parameter (line 130)

4. In `handleScaleDown`: change `r.newNodeManager(provider, scaler)` to `r.newNodeManagerWithHooks(provider)`.
5. In `handleMaxRuntimeRecycling`: change `r.newNodeManager(provider, scaler)` to `r.newNodeManagerWithHooks(provider)`.
