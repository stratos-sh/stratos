    2. **internal/controller/nodepool/lifecycle/node_launch.go** -- In `LaunchNode()`, add one line to the `templateConfig` struct literal (after the `EnableNetworkReadinessTaint` line):

       `pool.Spec.PreWarm` is `*PreWarmConfig`, can be nil. Direct assignment is safe.

    3. **internal/cloudprovider/aws/provider.go** -- In `generateEncodedUserData()`, inside the `if templateConfig != nil` block, add one line after the `EnableNetworkReadinessTaint` assignment:
       ```go
       bootstrapConfig.PreWarmConfig = templateConfig.PreWarmConfig
       ```

    4. **internal/controller/nodepool/reconciler.go** -- Wire `checkImagePrePullSupport` in the `reconcileNodePool()` method. Add the call early in the function, after `provider := r.getCloudProvider(nodePool.Name)` and before `r.handleScaleUp(...)`. This requires fetching the NodeClass first. Add these lines before the scale-up priority check:
       ```go
       // Check image pre-pull support (non-blocking, sets condition only)
       if nodeClass, ncErr := r.getNodeClass(ctx, nodePool.Spec.Template.NodeClassRef); ncErr == nil {
           r.checkImagePrePullSupport(nodePool, nodeClass)
       }
       ```
       Use a separate variable name (`ncErr`) to avoid shadowing. The call is non-blocking (void return), so errors fetching NodeClass are silently ignored here (NodeClass readiness was already validated in `Reconcile()` before `reconcileNodePool()` is called).
