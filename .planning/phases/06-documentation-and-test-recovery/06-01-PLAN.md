- Key types: Reconciler (implements reconcile.Reconciler). Delegates to lifecycle.Manager for node operations and strategy.ScalingStrategy for demand calculation.
- Role: Central orchestrator. Contains sub-packages lifecycle/ and nodestate/. Imports cloudprovider, config, metrics, and strategy.

**controller/nodepool/lifecycle** (manager.go:17 has old comment):

- Key types: Manager (provides Launch, Start, Stop, Sync, MonitorWarmup, MonitorCloudWarmup operations).
- Role: Encapsulates all cloud instance lifecycle interactions. Imports cloudprovider, metrics, and nodestate.

**strategy** (interface.go:17 has old comment):
- Purpose: Defines the ScalingStrategy abstraction for computing node demand.
- Key types: ScalingStrategy (interface with CheckDemand, Drain, HandleScaleDown methods), DemandResult, DrainResult.
- Role: Abstraction layer between controller and demand sources. Implementations live in sub-packages kubernetes/ and githubactions/.

**strategy/githubactions** (NO old comment -- githubactions.go has bare `package githubactions` on line 17):
- Purpose: GitHub Actions scaling strategy. Computes node demand based on queued GitHub Actions workflow jobs.
- Key types: Strategy (implements strategy.ScalingStrategy).
- Role: Imports strategy, cloudprovider, github, and nodestate. Alternative to the Kubernetes pod-demand strategy.

**strategy/kubernetes** (capacity.go:17 has old comment):

- Key types: Strategy (implements strategy.ScalingStrategy), plus capacity calculation, drain orchestration, network readiness checking, and startup taint management.
- Role: Primary strategy for most deployments. Imports strategy, cloudprovider, metrics, and nodestate.
