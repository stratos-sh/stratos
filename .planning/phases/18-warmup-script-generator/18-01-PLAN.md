  <files>internal/warmup/generator.go, internal/warmup/templates.go</files>
  <action>
Create the `internal/warmup/` package with two files.

**generator.go** - The generator function and supporting types:
- Package `warmup`
- Import `bytes`, `text/template`, and `stratosv1alpha1 "github.com/stratos-sh/stratos/api/v1alpha1"`
- `GenerateScript(images []string, policy stratosv1alpha1.ImagePullPolicy) string` function (returns string, not error -- template is compile-time constant, cannot fail at runtime; use `template.Must` to fail fast at init)
- If `len(images) == 0`, return `noOpScript` constant immediately
- Otherwise, build `templateData` struct and execute the parsed template into a `bytes.Buffer`
- `templateData` struct with fields: `Images []string`, `IsRequired bool`, `IsBestEffort bool`
- `noOpScript` constant: `#!/bin/bash\n# No images configured for pre-pull\nexit 0\n`
- Parse the template once at package init using `template.Must(template.New("warmup").Parse(scriptTemplate))` stored in a package-level var, not re-parsed on each call

**templates.go** - The bash script template as a raw string constant:
- Package `warmup`
- `scriptTemplate` constant (raw string using backticks)
- The template produces a flat sequential bash script (NOT bash functions) per CONTEXT.md decision

The generated script structure (top to bottom, flat):
1. `#!/bin/bash` shebang (NOT `set -euo pipefail` -- we handle errors explicitly per image)
2. Containerd readiness section: Wait for `/run/containerd/containerd.sock` socket (60s timeout, 2s poll). Then verify `ctr version` responds (shares the 60s timeout). Log "Containerd is ready" when both pass. Exit 1 if timeout exceeded.
3. ECR auth section (conditional): Check if ANY image matches `*.dkr.ecr.*.amazonaws.com` pattern. If so, extract region from the first ECR image URL and fetch one ECR token using `aws ecr get-login-password --region $region`. Store in variable. If token fetch fails, log warning and set empty token (pull will be attempted anyway -- image might be public). This section only appears when at least one image matches the ECR pattern. Use Go template logic to detect ECR images at generation time and set a `HasECRImages bool` and `ECRRegion string` field on templateData.
4. Per-image pull loop: For each image, inline the retry logic (flat, not a function call):
   - Log "Pulling <image> (attempt N/3)"
   - If image matches ECR pattern AND token is available, use `ctr -n k8s.io images pull --user "AWS:$ECR_PASSWORD" --label io.cri-containerd.pinned=pinned "<image>"`
   - If image does NOT match ECR pattern, use `ctr -n k8s.io images pull --label io.cri-containerd.pinned=pinned "<image>"`
   - On success: log "SUCCESS: Pulled <image> in Ns" (use SECONDS variable delta), break retry loop
   - On failure: if attempts remain, log "RETRY: Failed to pull <image>, waiting Ns" and sleep with exponential backoff (2s, 4s, 8s -- 3 attempts total, ceiling 30s per CONTEXT.md)
   - After all retries exhausted: log "FAILURE: Could not pull <image> after 3 attempts"
5. Policy-aware exit:
   - `{{if .IsRequired}}`: Track failures in a counter variable. After all images attempted, if failure_count > 0, log "ERROR: N image(s) failed to pull" and `exit 1`
   - `{{if .IsBestEffort}}`: No failure tracking needed. After all images, log "Image pre-pull completed (BestEffort)" and `exit 0`

IMPORTANT template details:
- Add `HasECRImages bool` and `ECRRegion string` fields to `templateData` in generator.go
- In `GenerateScript`, scan images for ECR pattern to populate these fields before template execution
- Use `{{range $i, $image := .Images}}` for iteration
- ECR detection at generation time: loop through images, if any matches ECR regex, set HasECRImages=true and extract region from first match
- Do NOT use bash functions in the template -- flat sequential per CONTEXT.md decision
- Image references are opaque strings -- do not parse registry/repo/tag, just pass to ctr
